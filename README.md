# Opera GX Auto-Update Blocker

Утилита на Python для полного отключения автоматических обновлений браузера **Opera GX** в Windows. Скрипт позволяет зафиксировать текущую версию браузера и предотвратить её перезапись без вашего ведома.

## Как это работает

Скрипт применяет 4 уровня защиты от фонового обновления:
1. **Переменная среды:** добавляет глобальную системную переменную `OPERA_AUTOUPDATE_DISABLED=1`.
2. **Блокировка доменов (`hosts`):** перенаправляет домены серверов обновлений (`://opera.com`, `://opera.com`) на `127.0.0.1`.
3. **Планировщик заданий Windows:** отключает фоновые задачи автообновления Opera (`schtasks`).
4. **Подмена исполняемого файла:** удаляет `opera_autoupdate.exe` и создаёт на его месте пустую папку с тем же именем, блокируя повторную загрузку файла системой.

## Требования

* ОС **Windows** (10 / 11)
* Установленный **Python 3.x**
* **Права администратора** (необходимы для редактирования файла `hosts`, планировщика задач и системных переменных)

## Как запустить

1. Склонируйте репозиторий или скачайте файл скрипта:
   ```bash
   git clone https://github.com
   cd НАЗВАНИЕ_РЕПОЗИТОРИЯ
   ```

2. Откройте командную строку (`cmd`) или PowerShell **от имени администратора**.

3. Запустите скрипт:
   ```bash
   python main.py
   ```
   *(замените `main.py` на фактическое имя вашего файла)*

4. Следуйте инструкциям в консоли: выберите стандартный путь установки Opera GX (`1`) или укажите папку с браузером вручную (`2`). После завершения работы скрипт автоматически перезапустит браузер.

## Примечания

* Перед началом работы скрипт принудительно закроет все активные окна и процессы `opera.exe` — сохраните открытые вкладки или несохранённые данные на страницах заранее.
* Некоторые антивирусы или встроенный Защитник Windows могут блокировать изменение файла `hosts` — при возникновении ошибки временно добавьте скрипт в исключения.
